# knn-classifier

Консольное приложение для классификации точек на плоскости методом k ближайших соседей (лабораторная работа № 1).

Версия: 1.2 (запрет дублирующихся точек в одном классе)

## Запуск

python knn.py

## Сохранение выборки

Программа сохраняет введённые точки в файл data.json и при следующем запуске предлагает использовать их снова.

## Запрет дублирующихся точек

Программа не позволяет добавить одну и ту же точку дважды в один класс. При попытке ввода дубликата выводится сообщение об ошибке, и ввод продолжается.
