# knn-classifier

Консольное приложение для классификации точек на плоскости методом k ближайших соседей (лабораторная работа № 1).

Версия: 1.1 (добавлено сохранение выборки)

## Запуск

python knn.py

## Сохранение выборки

Программа сохраняет введённые точки в файл data.json и при следующем запуске предлагает использовать их снова.
